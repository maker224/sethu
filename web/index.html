Your Mac, PC and phones,

Sethu is a small Rust server that puts your Mac, Windows PC, iPhone, iPad and Android devices in a browser tab — and moves files between them. Use it from Windows, Android, Linux or an iPad: no client installs, no third-party cloud.

  • Mac and Windows desktopsFull keyboard and mouse over native macOS Screen Sharing or a VNC server on Windows.
  • Phones and tabletsMirror iPhone, iPad and Android screens with tap, swipe and text input.
  • Yours aloneAccounts, sessions and device list live on your server. Device passwords are never stored.
  • Any file, any formatUpload from Android, Windows, iPhone or iPad and download on your MacBook from the shared Files tab.
  • Works in any browserConnect from Windows, Android, Linux, macOS or an iPad. Open several devices in separate tabs.

Add a Mac or Windows PC for full screen sharing, or an iPhone, iPad or Android device for mirrored touch control.

Mac in two minutes

  1. System Settings → General → Sharing → Screen Sharing on.
  2. Allow your macOS user, or set a VNC password under Computer Settings….
  3. Add the Mac's hostname or IP, port 5900.

Windows over VNC

  1. Install TightVNC, UltraVNC or RealVNC on the PC.
  2. Set a VNC password and allow port 5900 through Windows Firewall.
  3. Add the PC's hostname or IP, port 5900.

Windows Remote Desktop (RDP) is not proxied — use a VNC server.

iPhone / iPad mirroring

  1. Connect the device to a Mac and start WebDriverAgent.
  2. Forward port 8100 (iproxy or go-ios) so Sethu can reach it.
  3. Add http://mac-ip:8100 as an iPhone / iPad device.

Screenshots only, no audio. DRM video and the lock screen stay hidden by iOS.

Android over adb

  1. Enable Developer options → USB debugging (or wireless debugging).
  2. Run adb devices on the Sethu host and authorize the device.
  3. Add the serial, e.g. R58M… or 192.168.1.30:5555.

adb grants shell access to the device. Keep the Sethu host and adb trusted.
